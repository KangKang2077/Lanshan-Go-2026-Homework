# 蓝山 Go 2026 作业

本仓库按“周次 / 作业”分目录存放，每个作业目录都是可以独立编译、运行的 Go 模块。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `week_01_homework/` | 第一周作业：Go 基础语法练习（阶乘、平均数、循环求和等） |
| `week_06_web/` | 第六周作业：基于 Gin + JWT 的用户注册、登录、改密 Web 服务 |

## 运行方式

### 第一周作业

```bash
cd week_01_homework
go run .
```

### 第六周作业

```bash
cd week_06_web
go run .
```

服务默认监听 `:8080`，用户数据保存在运行目录下的 `data/user.json`。
部署时请通过环境变量 `JWT_SECRET` 设置自己的 JWT 密钥，不要使用代码里的开发密钥。

## 说明

- 每个作业目录都有自己的 `go.mod`，依赖互不影响。
- 编译产物（`*.exe`）和 IDE 配置（`.idea/`）不提交到仓库。
